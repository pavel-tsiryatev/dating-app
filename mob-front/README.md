# CAMPUS · mob-front

Мобильный веб-клиент по 7 листам / 42 экранам CAMPUS. Бежевый фон, красные акценты и фотографии из исходного архива. Телефон и компьютер; без npm-зависимостей, внешних шрифтов и CDN.

## Запуск

Нужен Node.js 20+. Установка зависимостей фронтенду не требуется:

```powershell
cd C:\Users\mrcbi\dating-app\mob-front
npm start
```

Открой http://127.0.0.1:5173. `/api/*` проксируется на http://127.0.0.1:3000. Другие адрес и порт задаются `API_URL` и `PORT`. Сервер слушает только loopback.

API запускается из `../apps/api`: `npm run build`, затем `npm start`. Нужны PostgreSQL, Redis, `.env` и применённые миграции. Пример конфигурации — `apps/api/.env.example`. При проблемах pnpm на Windows можно выполнить `npm install --package-lock=false` из `apps/api`; штатный pnpm-lock.yaml также обновлён.

## Локальные данные и режимы

`node scripts/seed-local.cjs` из `apps/api` создаёт проверочные аккаунты и события только в локальной базе `campus`, не сбрасывает существующие данные. Аккаунты: `audit.admin@urfu.me`, `audit.anna@urfu.me`, `audit.mark@urfu.me`, `audit.lena@urfu.me`. Вход обычным кодом; без SMTP код выводится в лог API. Паролей и обхода авторизации нет.

Обычный режим работает с NestJS/PostgreSQL/Redis. JWT хранится в sessionStorage. Чат, билет и заказ восстанавливаются после перезагрузки в этой вкладке. Выход очищает данные сессии. Сообщения и встречи обновляются каждые 5 секунд, ожидающий платёж — каждые 7 секунд.

«Посмотреть демо» включает отдельный адаптер в памяти без запросов к API. Код `123456`; деньги не списываются и письма не отправляются. Переключатель всех 42 экранов доступен справа на компьютере и под навигацией на телефоне. Перезагрузка сбрасывает данные демо.

## Сценарии через API

- Вход по почте и коду, 18+, анкета, 3–10 различных интересов, цель знакомства.
- Загрузка JPEG/PNG/WebP до 5 МБ, до 6 фото, обложка, порядок фото, удаление. Файлы хранятся локально API.
- Серверные фильтры возраста, цели, вуза и института; возраст без даты рождения, лайки/пропуски, взаимные и исходящие симпатии.
- Переписка, пагинация; встречи берутся из базы, а не из JSON в сообщениях. Второй участник может принять или отклонить встречу.
- Блокировки, скрытие от института, выключение видимости в ленте, тема и уведомления, удаление аккаунта.
- События с категориями/постерами, бронь 30 минут, отмена неоплаченной брони, платежи с идемпотентностью, отдельная проверка статуса, настоящий QR-билет и однократная отметка входа.
- Premium и история платежей; открытые/закрытые жалобы с контекстом; создание партнёров, редактирование событий/черновиков, статистика по дням и CSV.

## Тестовая оплата

`PAYMENT_PROVIDER=fake` возвращает ссылку на локальную песочницу. `PUBLIC_API_BASE` должен совпадать с origin фронтенда и содержать `/api`, например `http://127.0.0.1:5173/api`. Песочница открывается в той же вкладке для сохранения сессии. В ней можно подтвердить или отклонить тестовый платёж. Карта не нужна, деньги не списываются, webhook-секрет в браузер не передаётся. При `NODE_ENV=production` песочница недоступна.

Поздняя оплата отменённой/истёкшей брони не выдаёт лишний билет. Если билет выдать нельзя, интерфейс сообщает о необходимости сверки/возврата. Реальный платёжный провайдер и автоматический финансовый возврат не подключены.

## Проверки

```powershell
npm test
npm run build
```

`build` создаёт исключённую из Git папку `dist/`. Для статического хостинга нужен reverse proxy `/api` к NestJS; Node-прокси в сборку не входит.

`src/app.js` — экраны; `src/api.js` — HTTP/демо; `src/styles.css` — дизайн; `src/utils.js` — форматирование и URL. В `assets/references/` сохранены 7 исходных PNG; в `assets/*.jpg` — фотографии из макетов. `server.mjs` — сервер/прокси.

Подробный аудит новых методов, проверок и ограничений: `../docs/WEB_INTEGRATION_AUDIT.md`.
