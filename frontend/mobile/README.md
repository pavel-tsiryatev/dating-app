# CAMPUS · mobile

Мобильное приложение CAMPUS для Android и iOS: Expo SDK 55 (React Native 0.83), TypeScript, Expo Router.
Работает с тем же бэкендом, что и сайт: [`../../backend`](../../backend), контракт —
[`backend/openapi.json`](../../backend/openapi.json).

## Скачать APK

APK собирает GitHub Actions — workflow [`mobile-android.yml`](../../.github/workflows/mobile-android.yml):

- **из `main`** — раздел **Releases** репозитория, последняя «CAMPUS для Android · сборка N». Файл можно скачать прямо на телефон;
- **из любой ветки** — Actions → запуск «Mobile · Android APK» → Artifacts → `campus-android-apk` (zip с APK, нужен вход в GitHub);
- **вручную** — Actions → «Mobile · Android APK» → Run workflow.

Установка: открыть APK на телефоне и разрешить установку из этого источника.
APK подписан стандартным ключом сборки — для установки с файла этого достаточно, новые сборки ставятся поверх старых.
Для Google Play нужен собственный ключ подписи (см. «Что дальше»).

## Деморежим и сервер

- **«Посмотреть демо»** на первом экране — все сценарии на проверочных данных, без сети. Код входа `123456`, деньги не списываются.
- **Настоящий сервер.** Адрес API задаётся при сборке переменной `EXPO_PUBLIC_API_URL`
  (в GitHub — переменная репозитория `MOBILE_API_URL`). Если её нет, приложение спросит адрес на первом экране
  («Указать сервер»), его можно сменить в Настройках.
- **Свой компьютер как сервер.** Запусти бэкенд с `HOST=0.0.0.0`, телефон и компьютер — в одной Wi-Fi сети,
  адрес — `http://<IP компьютера>:3000`. HTTP без TLS в приложении разрешён для таких проверок.

С тестовым платёжным провайдером (`PAYMENT_PROVIDER=fake`) оплата подтверждается прямо в приложении
кнопками «Подтвердить оплату» / «Имитировать отказ». С настоящим провайдером откроется его страница оплаты.

## Что внутри

Экраны со всех 7 листов макетов (`frontend/web/assets/references/`); рассмотрение жалобы и решение модератора объединены в один экран:

| Лист | Экраны |
|---|---|
| Вход и подтверждение | приветствие, дата рождения и согласие, вуз и факультет, почта, код из письма, «Теперь ты среди своих» |
| Анкета и настройки | о себе, фото (загрузка с телефона, обложка, удаление), интересы, мой профиль, настройки, приватность |
| Знакомства | лента, анкета, фильтры, «Это взаимно!», симпатии (взаимные и исходящие), пустая лента |
| Чаты и безопасность | чаты, переписка, предложить встречу, встреча в переписке, жалоба, «Жалоба отправлена» |
| События и билеты | события, событие, бронь на 30 минут, мои билеты, билет с QR, «Все места заняты» |
| Оплата и Premium | Premium, оплата заказа, проверка оплаты, успех, отказ, «Время брони вышло» |
| Модерация и управление | очередь жалоб, рассмотрение и решение, события организатора, редактор события, отчёты, отметка входа |

Раздел «Команда CAMPUS» в профиле виден модераторам и администраторам; права всё равно проверяет сервер.

```
src/
├── app/              экраны (Expo Router: файл = маршрут)
│   ├── (tabs)/       нижнее меню: лента, симпатии, события, чаты, профиль
│   └── staff/        модерация и управление
├── components/       общие элементы: кнопки, поля, карточки, «кляксы» и штрихи из макетов
└── lib/
    ├── api.ts        клиент API (интерфейс CampusApi)
    ├── demo.ts       деморежим — та же CampusApi в памяти
    ├── session.tsx   токен (SecureStore), адрес сервера, текущий пользователь
    └── text.ts       форматирование: деньги, даты, склонение имён
```

## Разработка

Нужен Node.js 20+. Зависимости ставятся через npm (папка не входит в pnpm workspace — так проще для React Native):

```bash
cd frontend/mobile
npm install
npx expo start            # QR-код для Expo Go или development build
npx tsc --noEmit          # типы
npm test                  # юнит-тесты форматирования и модерации
```

Новые библиотеки — только через `npx expo install <пакет>`: он подбирает версии, совместимые с SDK 55.
Папки `android/` и `ios/` генерируются (`npx expo prebuild`) и в репозиторий не попадают — нативные настройки задаются в `app.json`.

Локальная сборка APK (нужны Android SDK и JDK 17):

```bash
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
# android/app/build/outputs/apk/release/app-release.apk
```

## Что дальше

- **Push-уведомления** — бэкенд пока пишет уведомления в лог (см. `docs/AUDIT.md`, B2).
- **Новые сообщения без опроса** — сейчас чат обновляется раз в 5 секунд (B3).
- **Долгая сессия** — refresh-токен вместо JWT на 7 дней (B1).
- **Публикация в Google Play** — собственный ключ подписи (EAS Build или keystore в секретах GitHub) и AAB вместо APK.
- **Premium в магазинах** — цифровые подписки в App Store и Google Play обычно требуют встроенных покупок.
- **Тёмная тема** — настройка сохраняется в аккаунте, но интерфейс пока только светлый.
